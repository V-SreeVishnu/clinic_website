# 🏥 Clinic Appointment Booking System

This project is a **clinic appointment booking website** where patients can book appointments online.  
When an appointment is booked, the doctor receives an **instant notification through a Telegram bot**.

🌐 Live Website:  
https://sree-venkateshwara-clinic.netlify.app

🤖 Telegram Bot:  
@VYGIRI_CLINIC_BOT


---

## 📌 Features

- Online appointment booking
- Instant Telegram notification to the doctor
- Simple and user-friendly interface
- Backend built using Django
- Hosted on Render
- Automated patient appointment alert system


---

## 🛠️ Tech Stack

**Frontend**
- HTML

**Backend**
- Python
- Django

**Database**
- SQLite

**Notification Service**
- Telegram Bot API

**Deployment**
- Render


---

## ⚙️ How It Works

1. Patient opens the clinic website.
2. Patient fills the appointment form.
3. Form data is sent to the Django backend.
4. Backend processes the appointment request.
5. A notification message is sent to the doctor via Telegram bot.
